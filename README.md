# 分批上线面板的处理效应估计

公开接口契约：仅修改environment/estimator.py，完整文件可编辑，可在文件内增加类和函数；其他交付文件固定。estimate(panel)接收JSON兼容对象，返回与queries同序的有限实数列表，布尔值不算数值。固定CLI为python3 cli.py，从标准输入读取一个UTF-8JSON对象，标准输出只写一个恰含effects字段的JSON对象；effects即返回列表，日志可写标准错误。每个面板在新的进程中独立调用。输入恰含periods、units、queries；periods为28，units为128项，每项含唯一字符串id、两个位于负1到1的实数协变量x、adoption和outcome。adoption为8、12、16或null，各有32个单位；null表示观察期内从未处理。outcome为28项列表，位置对应从0开始的时期，元素为有限实数或表示缺测的null。处理从adoption期起不可撤销，未处理潜在结果与处理后潜在结果之差为处理效应；处理前不存在预期效应，单位之间不存在干扰。queries为12项，每项含cohort和horizon，cohort取8、12、16，horizon取0、2、5、8；输出目标是在cohort加horizon时期，该批次全部32个单位的无噪声平均处理效应，包括该期缺测单位，不是观察到的结果水平或仅完整病例的均值。单位和查询顺序没有统计含义。面板包含单位水平差异、单位时间趋势、共同季节变化以及协变量相关的时变变化；处理批次与协变量相关，始终存在未处理单位，协变量支持有重叠。处理效应随批次、协变量和处理后时间变化，可能正向、负向、延迟生效或由正转负。观测噪声均值为零；缺测率可随已观测协变量变化，还可能有短期成块缺测，缺测机制不依赖未观测的结果噪声。开发和隐藏集均含趋势、季节、组成差异、延迟、反转和停采六族，每族三个独立种子，共18个面板；隐藏集重新抽取系数、噪声、单位及缺测掩码。生成器、隐藏真值和参考实现不向solver开放；开发输入与真值位于../eval_dev/inputs/和../eval_dev/answers/。本地运行python3 cli.py < ../eval_dev/inputs/trend_173.json，自测运行python3 selftest.py。研究方法、正则化和超参数可自由选择，仅使用Python标准库，运行不联网，不读取隐藏资源，不依赖持久跨面板状态。候选仅获得当前面板和自己的代码，每实例墙钟时限15秒，单CPU核，进程地址空间上限1GiB，标准输出上限1MiB；超时、异常退出、非JSON、多余字段、非有限数或输出长度错误使该实例得0分。修改固定文件、增加提交文件或提交符号链接使整题得0分；Python自动生成的缓存不参与提交。每实例先计算12项预测相对真值的RMSE，再分别计算三个批次内四项预测的RMSE并取最大值作为worst_cohort_rmse；实例分数为100乘以0.7乘max(0,1-RMSE/1.0)与0.3乘max(0,1-worst_cohort_rmse/1.5)之和，最终分数为18个实例的等权平均。零误差对应100分，1.0和1.5分别是两个误差分项归零的固定结果量纲锚点；参考数值仅用于表现校准，不是额外判零条件。候选输出不要求与参考实现相同，任意符合契约的方法都按相同真值计分。
