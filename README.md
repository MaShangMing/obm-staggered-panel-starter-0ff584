# 网络干扰下的分批上线策略效应

公开接口契约：仅修改environment/estimator.py，文件内的研究方法、模型结构和超参数自由选择，其他交付文件固定。estimate(panel)返回与queries同序的列表，每项恰含estimate、lower、upper三个有限实数，满足lower不大于estimate且estimate不大于upper，布尔值不算数值。estimate是策略A减策略B的平均因果效应，lower和upper是该效应的90%区间端点。固定CLI为python3 cli.py，从标准输入读取一个UTF-8JSON对象，标准输出只写一个恰含effects字段的JSON对象，effects为上述列表；日志写标准错误。输入恰含periods、units、weather、network、queries。periods为40、48、56或64，时间从0开始；units有240、320、400或480项，每项恰含唯一字符串id、四个负1到1之间的协变量x、整数block、整数stratum、adoption、outcome、auxiliary。block取0到11，表示共享部分观测扰动的群组；stratum为四个上线分层之一，分层标识是观察期内的整数，分层在反事实策略中不变。adoption为整数上线时期或null，null表示实际观察期内未上线；上线一旦发生不可撤销。实际四个上线时期在9到periods减17之间，各上线批次及从未上线单位约占五分之一。outcome和auxiliary各有periods项，元素为有限实数或表示缺测的null；两通道缺测掩码不同。weather有periods项，每项两个有限实数，是不受策略影响的共同环境观测。network与units同序，每行由5或6个邻居组成，每个邻居恰含id与正权重weight；无自环和重复邻居，行权重和为1，允许有向边。邻居身份以id关联。queries有36项，每项恰含kind、period、target、own_a、network_a、own_b、network_b。kind为direct、spillover或joint，分别标记只改变自身路径、只改变网络路径及同时改变两条路径的对比类型。period是目标时期，target是非空的目标单位列表，每项恰含id和正权重weight，总权重为1；目标可跨分层或只覆盖一个协变量子群，包含目标时期outcome缺测的单位。四个策略数组均与units同序，元素为0到periods减1的整数或null，含义与adoption相同。own_a和own_b指定每个单位自身的反事实上线时间；network_a和network_b分别指定用于构造邻居暴露的反事实上线时间。对任一网络策略，单位i在时期t的暴露等于其邻居中已上线单位的边权和；t小于0时暴露为0。自身处理和邻居暴露是两个分别可干预的输入，不能用own数组替代network数组。定义m_i(t;own,network)为在给定自身路径和网络路径下单位i的无观测噪声条件均值，保持协变量、分层、共同环境及自然变化不变；每个查询的真值为target权重下m_i(period;own_a,network_a)减m_i(period;own_b,network_b)的加权和。真值不是观测前后差、仅可见病例均值或两个独立总体的差。自然结果含单位水平和趋势、环境响应、协变量相关的共同时间变化，以及辅助通道所反映的潜在共同变化。auxiliary不受自身或邻居处理影响，它含低维共同变化及独立测量噪声，部分时期和单位不可观测。处理没有提前效应；自身效应依赖分层、协变量和上线后的时间，允许延迟、异号及反转。邻居影响可依赖当期和前三期暴露，并可与自身处理及协变量发生非线性交互；不存在图外或超过三期的邻居暴露记忆。实际上线与协变量相关，图中存在群组聚集；观测噪声异方差且同block内可能相关。缺测可随可见协变量变化，也有成块停采，不依赖当期未观测噪声。所有查询均在观察时间窗内，既包含实际策略与取消策略的对比，也包含提前上线的策略对比；反事实的协变量分布和分层身份保持不变。单位顺序、邻居顺序及查询顺序无统计含义，重排单位时四个策略数组和network行同步重排，target和邻居继续按id关联。开发和隐藏集各24个独立面板，覆盖diffusion、delayed、reversal、homophily、outage、overlap、nonlinear、mixed八类组合，每类三个种子；规模、上线时期、图、系数、噪声、辅助过程、缺测和查询对象均重新抽取，隐藏集不提供真值。开发输入与答案位于../eval_dev/inputs/和../eval_dev/answers/，运行python3 cli.py < ../eval_dev/inputs/diffusion_173.json，运行python3
